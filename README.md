# Taraz Road AI

Прототип для регистрации дорожных дефектов, показа заявок на карте и управления статусами.

## Важно перед запуском

- Приложение работает без весов модели в демонстрационном режиме.
- В демонстрационном режиме приложение **не распознаёт ямы с помощью ИИ**. Оно позволяет протестировать форму, сохранение заявок, карту и панель администрации.
- Чтобы включить реальное распознавание, положите совместимую YOLO-модель, обученную на дорожных дефектах, в `models/road_damage.pt`. Обычная модель YOLO для объектов общего назначения не обязательно умеет обнаруживать ямы.
- Не используйте тестовые координаты как реальные подтверждённые места дефектов.

## Запуск на Windows

1. Установите Python 3.11 с официального сайта Python и Git (необязательно).
2. Распакуйте проект и откройте PowerShell в папке `taraz-road-ai`.
3. Создайте виртуальное окружение:

   ```powershell
   py -3.11 -m venv .venv
   .\\.venv\\Scripts\\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```powershell
   streamlit run app.py
   ```

5. Откроется адрес, обычно `http://localhost:8501`.

Если PowerShell запрещает активацию окружения, можно запустить `.venv\\Scripts\\python.exe -m pip install -r requirements.txt`, затем `.venv\\Scripts\\python.exe -m streamlit run app.py`.

## Как протестировать

1. Откройте вкладку «Новая заявка».
2. Загрузите JPG или PNG.
3. Укажите тип дефекта, адрес/ориентир и координаты.
4. Сохраните заявку.
5. Проверьте метку на вкладке «Карта дефектов».
6. На вкладке «Панель администрации» измените статус.

## Структура

- `app.py` — интерфейс Streamlit.
- `services/detection.py` — вызов модели.
- `services/database.py` — SQLite и хранение фото.
- `services/priority.py` — примерный балл приоритета.
- `services/geolocation.py` — карта Folium.
- `models/` — положите сюда файл модели при наличии.

## Ограничения прототипа

- Балл приоритета — эвристика для демонстрации, не официальный стандарт.
- Координаты по умолчанию являются тестовыми.
- Нет авторизации, поэтому не публикуйте панель администратора с реальными персональными данными.
- Для публичного хостинга понадобится отдельное постоянное хранилище изображений и базы данных.
- Открытая карта может требовать интернет-соединения.
